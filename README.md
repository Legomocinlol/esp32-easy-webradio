# ESP32 Web Radio (MP3 Streamer + Equalizer)

Интернет-радио на **ESP32** с декодированием MP3 на лету (через лёгкий декодер `minimp3`), поддержкой HTTP/HTTPS потоков, автопоиском рабочих станций по любой стране мира, живым эквалайзером на OLED-дисплее и переключением станций по тачу.

---

## Необходимые компоненты

* **Микроконтроллер:** ESP32 (обычная ESP32-WROOM-32, PSRAM не требуется)
* **Аудиоусилитель (ЦАП):** MAX98357A (I2S) + динамик 3–5 Вт (4–8 Ом)
* **Дисплей:** OLED 0.96" 128×64 (SSD1306, интерфейс I2C)
* **Управление:**
  * Потенциометр (10 кОм) — регулировка громкости `0–100%`
  * Сенсорная кнопка TTP223 (или просто провод на `GPIO 27` для встроенного тача ESP32)

---

## Схема подключения (Распиновка)

| Компонент | Пин модуля | Пин ESP32 | Примечание |
| :--- | :--- | :--- | :--- |
| **OLED SSD1306** | `VCC` | `3.3V` | Питание экрана |
| | `GND` | `GND` | Общий минус |
| | `SDA` | `GPIO 21` | Линия данных I2C |
| | `SCL` | `GPIO 22` | Тактовая линия I2C |
| **MAX98357A (I2S)** | `VIN` | `5V` (или `3.3V`) | От `5V` звук громче |
| | `GND` | `GND` | Общий минус |
| | `BCLK` | `GPIO 16` | Тактовый сигнал I2S |
| | `LRC` | `GPIO 17` | Выбор канала I2S |
| | `DIN` | `GPIO 4` | Цифровой аудиосигнал |
| | `SD` | `GPIO 15` | Включение усилителя |
| **Потенциометр** | Крайние контакты | `3.3V` и `GND` | Питание делителя |
| | Средний контакт | `GPIO 33` | Регулировка громкости |
| **Тач / Кнопка** | `I/O` (TTP223) | `GPIO 18` | Внешний сенсор |
| | Провод / фольга | `GPIO 27` | Встроенный емкостный тач ESP32 |

## Установка и запуск

1. **Скачайте репозиторий** и убедитесь, что в одной папке лежат два файла:
   * `ESP32-Web-Radio.ino`
   * `minimp3.h`
2. **Установите библиотеку для экрана:**
   * В Arduino IDE откройте **Менеджер библиотек** (`Ctrl + Shift + I`), найдите **`U8g2`** (автор *oliver*) и установите её.
3. **Настройте Wi-Fi и страну в начале скетча:**
   * Впишите имя и пароль вашей сети в `WIFI_SSID` и `WIFI_PASS`.
   * В переменной `COUNTRY_CODE` укажите код страны (`"KZ"`, `"RU"`, `"UA"`, `"BY"`, `"US"`) или оставьте `""` для загрузки мирового топа станций.
4. **Настройки платы в Arduino IDE:**
   * **Board:** `ESP32 Dev Module`
   * **PSRAM:** `Disabled`
   * **Upload Speed:** `921600` (или `115200`)
5. Нажмите **Загрузка (Upload)**.

## Особенности работы

* **Автопоиск станций:** При включении ESP32 автоматически скачивает актуальный список живых MP3-потоков через API *Radio Browser*. Если станция недоступна или соединение оборвалось более чем на 12 секунд — радио само переключит на следующую волну.
* **Буфер 32 КБ:** Сглаживает кратковременные провалы при слабом сигнале Wi-Fi.
* **Поддержка кириллицы:** Названия станций на русском и казахском языках корректно отображаются на экране без искажений.
